# [ZKT-Adaptive-navbar](https://zik-kurat.github.io/ZKT-Adaptive-navbar/)

Практика по написанию адаптивного навбара.
* При переполнении пункты навбара скрываются по одному и появляются в модальном окне.
* Бургер появляется/исчезает в зависимости от наличия скрытых пунктов.

Главная фича: Отсутсвие заранее заданных брейкпоинтов. Переполнение отслеживается JS и запускает анимации и смену стилей.
